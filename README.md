# 知点

观看哔哩哔哩视频时，自动提炼分类知识点，并在播放页侧栏和本地知识库中保留对应时间点。

## 本地启动

1. 双击 [start.cmd](start.cmd)。首次启动会创建 Python 虚拟环境并安装依赖，请等到浏览器打开 `http://127.0.0.1:8765/`。以后也用同一文件启动。
2. 在网页的“AI 设置”里填写 API 地址、知识点整理模型、语音转写模型和 API 密钥。默认地址与模型适用于 OpenAI；其他兼容服务需同时支持 `/chat/completions`，无字幕视频还需支持 `/audio/transcriptions`。
3. 在 Edge 打开 `edge://extensions`，或在 Chrome 打开 `chrome://extensions`；开启“开发人员模式”，点击“加载解压缩的扩展程序”，选择本目录的 `extension` 文件夹。扩展只需安装一次，更新扩展文件后在扩展管理页点击刷新。
4. 打开或刷新哔哩哔哩视频播放页。右上角会出现“知识点”按钮；默认在主播放器播放数秒后自动整理有字幕的视频。可在侧栏关闭自动整理，或手动开始。没有字幕时，必须在侧栏确认“转写音频”后才会下载音频并调用转写服务。整理过程中可停止当前任务；处理较长视频时，已完成的片段会先显示出来。

本地网页也可以直接粘贴 B 站视频链接。整理过的视频会保存在知识库里；再次打开同一视频会读取已有结果。“重新整理”会重新调用 AI 服务。知识库可跨视频搜索知识点，点击时间点回看原片，修订或标记待核对的知识点，并将视频笔记导出为 Markdown。分段结果在整段任务完成前只是预览；完成后才会保存到知识库。

## 数据与限制

- 优先使用视频已有字幕。无字幕转写经确认后才会临时下载公开可访问的音频；登录限制、地区限制或 B 站访问限制可能导致失败。超过 4 小时的视频不进行音频转写。
- 字幕或转写内容会发送到你在设置中填写的 AI 服务，调用可能产生费用。界面显示视频时长，但实际价格由你选择的服务决定。转写服务没有返回分段时间时，时间点会显示“约”。
- 知识点由 AI 从字幕或转写文字提炼，引用的时间点取自对应文本片段。引用存在不等于解释一定正确；重要结论请结合原话核对，发现问题可在知识库中修订或标记待核对。
- 从 B 站课程总结导入的笔记会标注“B站课程总结”来源，引用内容显示为“摘要依据”。这类内容可能是概括而非逐字原话，重要结论仍需回看视频核对。
- 本地模式下，设置和整理结果保存在当前电脑的 `%LOCALAPPDATA%\VideoKnowledge`。云端模式下，设置和整理结果保存在服务器的持久磁盘 `/var/data`；部署后不会自动上传本地旧数据。API 密钥保存在该目录的 `config.json` 中，不会由读取设置的接口返回；文件本身未加密，不适合在共用账户中保存密钥。
- 本产品不会修改 `study` 目录中现有的学习笔记、学习计划或周报。

关闭本地服务后，扩展会显示连接失败；重新运行 `start.cmd` 后在播放页点击“重新整理”即可。

## 云端部署（Render）

`render.yaml` 定义一台付费的 0.5 CPU / 512 MB 实例和 1 GB 持久磁盘。创建服务后会持续计费，具体金额以 Render 创建页面为准。持久磁盘用于保存 `videos.sqlite3` 和 `config.json`；不要把这两个文件或任何密钥提交到公开的 GitHub 仓库。源代码可以公开，知识库 API 需要访问令牌。Dockerfile 设有 `ZK_REQUIRE_AUTH=1`，容器缺少 `ZK_PUBLIC_URL` 或 `ZK_ACCESS_TOKEN` 时会拒绝启动。云端只运行一个进程和一个实例，以免 SQLite 和内存中的整理任务状态分散。

1. 把本目录的源代码推送到自己的公开 GitHub 仓库。在 [Render Dashboard](https://dashboard.render.com/) 选择 **New > Blueprint**，连接仓库并检查显示的实例和磁盘费用，然后创建服务。`autoDeployTrigger: off` 表示以后需要手动触发部署。
2. 创建 Blueprint 时填写 `ZK_PUBLIC_URL`，格式为 Render 给这个服务分配的完整 HTTPS 源地址，例如 `https://zhidian-hypemyself.onrender.com`，末尾不要带路径。如果实际分配地址不同，在 Render 的 **Environment** 中改成实际地址并重新部署。填写 `ZK_ACCESS_TOKEN`，使用独立的、至少 32 个可见 ASCII 字符的随机令牌，并保存在密码管理器中。可运行 `python -c "import secrets; print(secrets.token_urlsafe(48))"` 生成令牌。不要把令牌写进仓库。
3. 打开云端网址，在登录页输入该令牌，再在“AI 设置”中配置自己的 AI 服务地址、模型和 API 密钥。Render 服务器必须能访问 AI 服务和 B 站；网络或地区限制可能使抓取和转写失败。
4. 在 Edge 的 `edge://extensions` 中重新加载本目录 `extension` 文件夹的最新版本。打开扩展的“选项”，把服务地址设为同一个 HTTPS 地址，输入同一个访问令牌并检查连接。之后打开 B 站视频页即可使用云端知识库。

浏览器里的登录令牌只保存在当前标签页会话中；扩展令牌保存在当前浏览器扩展的存储中。云端服务初次启动是空知识库，本机 `%LOCALAPPDATA%\VideoKnowledge` 中的旧笔记不会自动迁移，原文件也不会被删除。要保留旧笔记，请先单独备份本地 `videos.sqlite3` 和 `config.json`，再安排私密迁移。Render 持久磁盘有快照，但仍建议定期导出重要笔记；删除云服务或磁盘前先备份。
